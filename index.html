Panduan Penggunaan

Cara update data dan gambar katalog.

1. Update Data Katalog (Upload PMR17RA)

Buka menu Update Data (Excel), lalu upload file laporan PMR17RA (.xlsx / .xls / .xlsb / .csv). Sistem akan membaca data dan memperbarui katalog secara otomatis.

2. Perhatian Khusus Data PMR17RA

  • Stock Code — hilangkan angka nol di depan. Contoh: "0000123" harus jadi "123".
  • Price — pastikan format kolom adalah Accounting (bukan General/Number biasa), supaya nilai terbaca benar oleh sistem.

3. Update Gambar Katalog

  1. Klik menu Katalog atau Katalog Visual.
  2. Klik / pilih item yang akan ditambahkan gambar.
  3. Upload gambar dari galeri, atau ambil foto langsung dari kamera (bisa lebih dari 1 foto sekaligus).
  4. Klik Simpan.

4. Menghapus Gambar yang Salah Upload

Jika ada gambar yang salah ter-upload, buka kembali item tersebut lalu klik tombol Delete pada foto yang ingin dihapus.
